# درس‌چین

درس‌چین یک اپ مستقل React/Vite برای حل مسئله **زمان‌بندی دروس دانشگاهی** است. گروه‌های درسی، استادان و تعداد جلسات از قبل مشخص‌اند و موتور، هر جلسه را به یک زمان شروع و فضای آموزشی تخصیص می‌دهد.

این نسخه بازطراحی کامل پروژه قبلی است و داده نمونه آن نیز از آموزشگاه به یک دانشکده دانشگاهی تغییر کرده است.

## امکانات اصلی

- تعریف چند جلسه هفتگی برای هر گروه درسی
- پشتیبانی از جلسات چندبازه‌ای و پیوستگی زمان آن‌ها
- چند استاد و چند گروه دانشجویی برای یک درس
- کلاس نظری، سایت رایانه، آزمایشگاه، کارگاه و آتلیه
- ظرفیت، تجهیزات، ساختمان و رزرو زمانی فضاها
- زمان‌های ممنوع و مطلوب برای استاد، دانشجو، درس و فضا
- کلاس ثابت و زمان ثابت برای هر جلسه
- هفته‌های عادی، زوج و فرد
- تعارض صریح سخت یا نرم بین دو درس
- تشخیص دلیل تخصیص‌نیافتن جلسات
- نمایش برنامه به تفکیک استاد، ورودی، درس و فضای آموزشی
- خروجی CSV و ورود/خروج کامل JSON

## قیود سخت پیاده‌سازی‌شده

1. هر جلسه حداکثر یک تخصیص معتبر دارد و نتیجه، جلسات تخصیص‌نیافته را جدا گزارش می‌کند.
2. تمام بازه‌های یک جلسه چندبازه‌ای متوالی و در یک روز هستند.
3. اتاق، استاد و گروه دانشجویی در بازه‌های زمانی مشترک دوباره رزرو نمی‌شوند.
4. ظرفیت، نوع فضا و تمام تجهیزات موردنیاز کنترل می‌شوند.
5. زمان تعطیلی دانشگاه، عدم حضور استاد/دانشجو و رزرو اتاق رعایت می‌شود.
6. کلاس ثابت و زمان ثابت جلسه رعایت می‌شوند.
7. جلسات یک درس می‌توانند الزاماً در روزهای متفاوت قرار گیرند.
8. حداقل فاصله روزانه جلسات می‌تواند سخت یا نرم باشد.
9. سقف بار روزانه و تعداد بازه‌های متوالی استاد و دانشجو کنترل می‌شود.
10. برای ساختمان‌های متفاوت می‌توان زمان جابه‌جایی اجباری تعیین کرد.
11. برخورد جلسات هفته‌های زوج و فرد فقط در صورت اشتراک هفته بررسی می‌شود.
12. تعارض‌های صریح سخت، هم‌زمانی دو درس را ممنوع می‌کنند.

## معیارهای نرم تابع هدف

- ترجیح زمانی استاد
- ترجیح زمانی گروه دانشجویی
- ترجیح زمانی خود درس
- فاصله مناسب جلسات یک درس
- ثبات کلاس و کلاس ترجیحی
- کاهش اتلاف ظرفیت اتاق
- کاهش کلاس‌های انتهای روز
- کاهش فاصله‌های خالی برنامه استاد و دانشجو
- کاهش تعارض دروس اختیاری بر اساس وزن مشترک

وزن هر معیار از داخل رابط یا JSON قابل تغییر است. محدودیت سخت با وزن مدل نمی‌شود و همیشه باید برقرار باشد.

## اجرای محلی

نیازمندی: Node.js نسخه 20 یا جدیدتر.

```bash
npm install
npm run dev
```

ساخت نسخه تولیدی:

```bash
npm run build
npm run preview
```

## انتشار روی Vercel

پروژه را در یک مخزن Git قرار دهید و در Vercel وارد کنید. تنظیمات لازم در `vercel.json` قرار دارند:

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

پروژه به پایگاه داده، متغیر محیطی یا سرویس خارجی وابسته نیست و حل مسئله در مرورگر انجام می‌شود.

## مدل ورودی JSON

فایل کامل نمونه در `examples/sample-university.json` قرار دارد. ساختار خلاصه:

```json
{
  "courses": [
    {
      "id": "CS201",
      "code": "CS-201",
      "name": "طراحی الگوریتم‌ها",
      "instructors": ["دکتر احمدی"],
      "studentGroups": ["کامپیوتر ۱۴۰۳-الف"],
      "enrollment": 32,
      "meetingsPerWeek": 2,
      "duration": 1,
      "roomType": "lecture",
      "requiredFeatures": ["پروژکتور"],
      "fixedRoomId": "",
      "fixedSlots": { "1": "0-1" },
      "forbiddenSlots": [],
      "preferredSlots": ["0-1", "3-1"],
      "minDayGap": 2,
      "roomConsistency": true,
      "weekPattern": "all"
    }
  ],
  "rooms": [
    {
      "id": "A101",
      "name": "کلاس A101",
      "building": "دانشکده فنی",
      "capacity": 80,
      "roomType": "lecture",
      "features": ["پروژکتور"],
      "unavailableSlots": []
    }
  ]
}
```

## قالب بازه زمانی

هر بازه با قالب `روز-بازه` و اندیس صفر نوشته می‌شود:

- `0-0`: شنبه، بازه اول
- `2-3`: دوشنبه، بازه چهارم
- `5-1`: پنج‌شنبه، بازه دوم

در `fixedSlots` کلید، شماره جلسه از یک است. برای نمونه `{ "2": "3-0" }` جلسه دوم درس را در سه‌شنبه، بازه اول ثابت می‌کند.

## روش حل

موتور ابتدا دامنه مجاز هر جلسه را با حذف زوج‌های نامعتبر زمان–اتاق می‌سازد. سپس با ترتیب‌دهی «محدودترین جلسه اول»، جست‌وجوی چندآغازه تصادفی و بهبود محلی، جواب‌های امکان‌پذیر را تولید و بر اساس تابع جریمه مقایسه می‌کند. این روش برای اجرای مستقل در مرورگر طراحی شده است؛ برای داده‌های بسیار بزرگ سازمانی می‌توان همین مدل داده را به یک حل‌کننده CP-SAT یا MILP سمت سرور متصل کرد.
