# Security Policy

## Reporting a vulnerability

Please do not publish sensitive university scheduling data, exploit payloads, or secrets in a public issue.

Report a vulnerability privately to the repository owner through GitHub's private vulnerability reporting feature when enabled, or contact the creator through the approved profile:

https://www.linkedin.com/in/hossein-karimi-8a452153/

Include a minimal non-destructive reproduction, the affected version or deployment URL, expected impact, and suggested mitigation when known.

## Scope

The browser application, JSON and Excel import/export, Vercel Python function, CP-SAT resource limits, security headers, and dependency supply chain are in scope. Client-side processing reduces routine data transfer for the fast solver but is not an absolute security guarantee.
